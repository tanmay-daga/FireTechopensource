# Code of Conduct

We want Bug Buster to be a safe, welcoming space for everyone.

- Be respectful to every contributor, maintainer and user.
- Do not harass, discriminate or disrupt.
- Give and accept constructive feedback gracefully.

This project follows the [MLH Code of Conduct](https://mlh.io/code-of-conduct).
To report a problem, email incidents@mlh.io or contact the maintainers.
