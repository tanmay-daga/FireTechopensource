Why there is no live demo on this page

Bug Buster runs Gemma 3 through Ollama on your own computer and reads a folder on that same computer. Neither exists on a web host, so the tool is installed and run locally rather than deployed. That is deliberate: your source code and your screenshots never leave your machine, there are no API keys, and there is no per-request cost. This page documents the project — the repository is the submission.

How it works

Two model passes, with a safety check before anything reaches you.

01

Read the screenshot

Gemma describes what is visibly wrong: text, errors, layout, colour and alignment.

02

Scan the repo

A bounded scanner reads source files only, skipping secrets, lockfiles and binaries.

03

Find the culprit

Gemma gets the description plus the most relevant files and must answer in strict JSON.

04

Verify the patch

The diff is checked against your real files. Nothing is ever applied automatically.

Run it on your machine

You need Python 3 and Ollama.

git clone https://github.com/tanmay-daga/FireTechopensource.git bugbuster
cd bugbuster/backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
ollama pull gemma3:4b
python3 main.py

Then open http://localhost:8000. The backend serves the interface itself, so there is nothing else to start.
